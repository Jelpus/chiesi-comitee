## Committee planning automation

The Admin area includes `/admin/settings` for the Committee responsible and default date offsets, and `/admin/planning` for the editable Committee calendar.

Production runs the planning processor every day at 12:00 UTC through Vercel Cron. Configure `CRON_SECRET` in the production environment; Vercel sends it as a bearer token to `/api/cron/committee-planning`. The processor uses `America/Mexico_City` as its business date and records successful events so scheduled emails are not repeated. Version 1 and its first Request Info are opened automatically on the first day of the reporting month.

The required BigQuery tables are created lazily by the app. The equivalent deployment migration is available at `sql/admin/009_app_settings_and_committee_planning.sql`.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
